# Exception queue page design

Arita redesigned the exception queue page in Claude Design on 13 Nov 2026. Story #152 builds it.

- `queue-page.dc.html`: the page, with the list on the left and the selected item on the right.
- `logo-and-favicon.dc.html`: the ARGUS mark, the favicon sizes and the color palette.

These files are a copy of the Claude Design source. They need the Claude Design runtime and do not open in a browser on their own. Read them for the exact colors, sizes and spacing. Issue #152 describes the design in words and lists the acceptance criteria. The sample data in them is synthetic.
